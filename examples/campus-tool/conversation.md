# Example: Campus Tool Idea / 示例：校园工具想法

## User / 用户

我是大学生，想做一个校园工具，帮学生聚合网上信息和资源，比如番剧资源整理，或者网购多平台比价。项目不商业化，想开源到 GitHub，目标是有人用和有 star。我主要依赖 AI 编程，能写原型，但不确定能不能长期调试和维护复杂后端。

## Agent / 拷打官

这个方向最大问题不是页面，而是数据源。

先质疑条件：

1. 你是否有稳定、合法的数据来源？
2. 你能维护反爬、登录、价格变动、版权风险吗？
3. 如果不能自动爬平台，这个项目还成立吗？

## User / 用户

我觉得可能不太适合。那做面向大学生的 AI prompt/agent workflows 呢？

## Agent / 拷打官

这条路更适合你，但也别幻想。

优势：

- 不需要后端
- 不依赖学校权限
- GitHub 展示友好
- 适合你自己长期维护

风险：

- 纯 prompt repo 容易像高级废话
- 受众比普通学生窄
- 必须有模板、流程、示例输出
- 必须解决真实场景，不是“万能 AI 助手”

先砍范围：只做一个强 workflow：`grill-my-project-idea`。

核心不是“评价创意”，而是质疑用户条件：时间、人+AI可维护性、预算、数据、权限、用户、维护、分发。

## Result / 结果

项目被压缩为：

> 一个中英双语 AI agent workflow，帮助学生和新手开发者在写代码前拷打项目想法，发现不现实条件，并输出 MVP 规格和两周验证计划。
