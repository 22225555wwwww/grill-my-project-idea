# MVP Spec / MVP 规格

## One Core Path / 一个核心路径

A student developer with a vague project idea uses this workflow to expose unrealistic constraints and gets a two-week-testable MVP spec.

一个学生开发者有模糊项目想法，用这个 workflow 发现不现实条件，并得到两周可验证 MVP 规格。

## Must Build / 必须做

- 中文 workflow
- 英文 workflow
- README：中文在前，英文在后
- 条件审计模板
- 假设账本模板
- 风险表模板
- MVP 规格模板
- 两周验证计划模板
- 一个完整示例

## Not Now / 暂不做

- CLI 工具
- Web UI
- 多平台安装脚本
- 大量 workflow pack
- 自动生成文档工具

## Explicitly Won't Build / 明确不做

- 商业计划生成器
- 万能创业导师
- 替用户做法律/财务/医疗判断
- 只夸不质疑的灵感 prompt

## Success Criteria / 成功标准

- 用户能在 5 分钟内复制 workflow 开始使用
- workflow 一次最多问 3 个问题
- 输出能明确指出最大资源矛盾
- MVP 能被压缩到两周内可验证

## Failure Criteria / 失败标准

- 输出变成空泛鼓励
- 用户条件没有被审计
- 建议依赖不存在的预算/API/用户/权限
- workflow 太长导致没人愿意读

## First Issues / 首批任务

1. Write Chinese workflow
2. Translate English workflow
3. Add reusable templates
4. Add realistic example
5. Improve README quick start
