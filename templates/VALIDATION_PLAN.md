# Validation Plan / 验证计划

## Goal / 目标

Validate whether **[target user]** has **[problem]** strongly enough to try **[MVP]**.

验证 **[目标用户]** 是否真的有 **[问题]**，且愿意尝试 **[MVP]**。

Effective validation requires: real target user, real context or materials, one core action, observable behavior, negative feedback, and a decision change.

有效验证必须包含：真实目标用户、真实场景或材料、一个核心动作、可观察行为、负反馈，以及因此产生的项目决策变化。

Invalid validation: friend praise, demo watching, likes/stars, vague compliments, or “I would use this if it had more features”.

无效验证：朋友夸奖、围观 demo、点赞/star、模糊好评，或“如果功能更多我会用”。
